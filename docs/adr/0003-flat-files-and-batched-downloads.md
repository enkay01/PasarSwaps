# Flat files and batched downloads, with no catalogue and no web UI

The previous lab, `market-research-lab`, reached roughly 15,000 to 20,000 lines across about 40 modules, with a DuckDB catalogue, Parquet datasets, point-in-time eligibility columns, a React frontend and a security-list service with its own contract tests. It failed at the one step that mattered: its providers fetched one symbol per call, its free tiers allowed a request every twelve seconds, its runs died partway on a rate limit or an incomplete read, and nothing resumed. This repository stores one Parquet file per Dataset and downloads from a Source that takes a symbol list per request. It has no database, no catalogue, no web UI and no scheduler. The rule this gives later Features: if a step cannot finish a 500 symbol universe on a free tier, the step is wrong.
